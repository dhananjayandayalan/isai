# P0 plan — Foundation

## Goals

A skeleton where every command in `CLAUDE.md` and `.claude/commands/` runs: the Song
contract exists with generated types on both sides, the pipeline CLI stub writes a valid
Song, the web page shows an example song, `theory/` has its first tested code, and the
three founding ADRs plus the golden manifest are in place. No audio, MIDI library, sound or
piano rendering.

## Prerequisites and decisions to confirm

1. **`uv` is not installed** on this machine (Python 3.11.1, Node 24, pnpm 12 are). Please
   install it, e.g. `! powershell -c "irm https://astral.sh/uv/install.ps1 | iex"` or
   `! winget install astral-sh.uv`, then restart the session so it is on `PATH`.
2. **Branches.** There is only `master`; `/phase-review` diffs against `main`. Plan: create
   `main` at the current commit and do P0 on `p0-foundation`. (Not merging or pushing.)
3. **Line endings.** `core.autocrlf=true`; add `.gitattributes` (`* text=auto eol=lf`) so
   generated files are byte-identical across runs and `/schema-sync` shows no diff.
4. **Schema choices beyond the spec** (it is new, so no version bump):
   - `additionalProperties: false` on every object (strict contract).
   - `chords[].quality` is an enum (Harte-style shorthand): `maj min dim aug sus2 sus4 5
     maj6 min6 7 maj7 min7 minmaj7 dim7 hdim7 9 maj9 min9 add9`. Adding values later counts
     as breaking for consumers, so this is the moment to object.
   - `tonality.key` pattern `^[A-G](#|b)?$`; `scale` unique ints 0–11; `bass` pitch class;
     `timeSignature.den` in {2, 4, 8, 16}; confidences 0–1; `meta.createdAt` is date-time;
     `schemaVersion` is `const "0.1.0"`.
   - `end > start` cannot be expressed in JSON Schema; the pipeline enforces it in code later.
5. **Dependencies** (all named or implied by the spec; none over ~5 MB except pyright,
   which the spec requires and which downloads its own Node bundle):
   - pipeline runtime: `pydantic>=2`, `jsonschema` (CLI validates its output against the
     schema). CLI uses stdlib `argparse`, not typer.
   - pipeline dev: `ruff`, `pyright`, `pytest`, `pytest-cov`, `datamodel-code-generator`.
   - web runtime: `react`, `react-dom`, `ajv` (validate Song JSON at load time; it will
     come from the worker later).
   - web dev: `vite`, `@vitejs/plugin-react`, `typescript`, `vitest`, `eslint`,
     `@eslint/js`, `typescript-eslint`, `eslint-plugin-react-hooks`,
     `eslint-plugin-react-refresh`, `globals`, `json-schema-to-typescript`, `@types/*`.

No new ADRs beyond the three the spec asks for, and nothing from a later phase.

## Files

**Repo root:** `.gitignore` (spec list + `.cache/`, coverage output), `.gitattributes`,
`.env.example` (`SUPABASE_URL`, `SUPABASE_ANON_KEY`), `README.md`.

**Schema:** `schema/song.schema.json` (`$defs`: Tempo, TimeSignature, Tonality, Chord, Note,
Section, Meta, Confidence, each with a `title` so both generators name types the same);
`schema/examples/twinkle-g-major.json` (both hands, chords, sections),
`schema/examples/frere-jacques-a-cappella.json` (melody only, right hand),
`schema/examples/invalid-out-of-range.json` (MIDI 130, missing `tonality`).

**Pipeline:**
- `pyproject.toml` (hatchling, `src/` layout, scripts `isai = isai.cli:main`,
  `gen-models = isai.gen_models:main`; ruff, pyright strict on `src/`, pytest marker `slow`,
  coverage config), `README.md`, `uv.lock`.
- `src/isai/{ingest,separate,rhythm,tonality,transcribe,harmony,arrange,theory,worker}/__init__.py`.
- `src/isai/schema.py` — locate `schema/` (walk up from the package, `ISAI_SCHEMA_DIR`
  override), load schema/examples, `validate_song()`.
- `src/isai/gen_models.py` — runs datamodel-codegen (pydantic v2, no timestamp) into
  `src/isai/generated/song.py`.
- `src/isai/cli.py` — `isai analyse <file> --out <dir> [--title]`: checks the file exists,
  copies the G-major example, sets `id`/`title`/`createdAt`/`pipelineVersion`, validates,
  writes `<out>/<stem>.song.json`. Non-zero exit with a clear message on a missing file.
- `src/isai/theory/pitch.py` — `pitch_class_to_name(pc, prefer="sharp"|"flat")`,
  `name_to_pitch_class("C#"|"Db"|"E♭"|"B#"|...)`, `midi_to_name(60) == "C4"`,
  `name_to_midi("Cb4") == 59`, range checks.
- `src/isai/theory/scales.py` — `scale(tonic, mode)` for major/minor plus church modes and
  harmonic/melodic minor, returning pitch classes in scale order.
- `tests/`: `test_schema.py`, `test_generated_models.py`, `test_cli.py`,
  `theory/test_pitch.py`, `theory/test_scales.py`.

**Web:**
- `package.json` (scripts `dev build test lint typecheck gen:types`), `pnpm-lock.yaml`,
  `tsconfig*.json` (strict), `vite.config.ts` (allows reading `../schema`), `eslint.config.js`
  (ignores `src/generated/`), `index.html`.
- `src/{audio,piano,engine,theory}/index.ts` empty modules; `src/generated/song.ts` from
  `gen:types`.
- `src/midi/MidiInput.ts` — `MidiDevice`, `MidiNoteEvent`, `MidiInput` interface
  (`listDevices`, `connect`, `onNoteOn`, `onNoteOff` returning an unsubscribe, `disconnect`);
  `src/midi/FakeMidiInput.ts` with `emitNoteOn/emitNoteOff`; `src/midi/index.ts`.
- `src/song.ts` — `parseSong(json: unknown): Song` (ajv 2020-12 against the schema).
- `src/App.tsx`, `src/main.tsx` — one page: title, key + mode, BPM, note count.
- Tests: `song.test.ts` (examples parse, invalid one throws, typed fields readable),
  `midi/FakeMidiInput.test.ts`, `App.test.tsx` (server-render the page and check the four
  values, so the dev-page criterion is covered by a test as well as by hand).

**Golden set:** `tests/golden/manifest.yaml` (3 entries: piano-solo, full-mix, a-cappella,
`audio: TODO`, expected key/tonic/tempo, optional `chords_lab`/`midi`), `tests/golden/README.md`.

**Docs:** `docs/adr/0001-record-architecture-decisions.md`, `0002-song-json-contract.md`,
`0003-midi-behind-interface.md` (all `accepted`, as the spec states).

## Exit criteria (from spec)

- [ ] `uv sync`, `uv run pytest`, `uv run ruff check .`, `uv run pyright` all pass in `pipeline/`
- [ ] `pnpm install`, `pnpm test --run`, `pnpm lint`, `pnpm typecheck`, `pnpm build` all pass in `web/`
- [ ] `/schema-sync` regenerates both type sets with no diff on a clean tree
- [ ] `uv run isai analyse README.md --out .cache/p0` writes a Song JSON that validates
- [ ] `pnpm dev` page shows the example song's title, key, tempo and note count
- [ ] `theory/` coverage ≥ 90%
- [ ] Three ADRs present and accepted; golden manifest present
- [ ] Everything committed in small conventional commits

`/golden-eval` is not run in P0: there is no audio and no real pipeline behaviour yet.
